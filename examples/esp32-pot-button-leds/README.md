# ESP32 with a pot, a button and two LEDs

The circuit of [esp32-button-led](../esp32-button-led), drawn on the
`wokwi-esp32-devkit-v1` board, which wokwi-elements can show. It runs the
same firmware: `firmware.bin` is a link to that example's image.

Open it in the web demo: `web/?demo=examples/esp32-pot-button-leds`.
